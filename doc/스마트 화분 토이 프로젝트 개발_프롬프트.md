# 스마트 화분 토이 프로젝트 개발 프롬프트

## 1. 프로젝트 개요 정의
- **목표**: FPGA 기반 스마트 화분 시스템 개발
- **기능 범위**: 환경 모니터링, 자동 급수, 사용자 인터페이스
- **구현 방식**: 다음 질문에 답변해주세요
  - 어떤 센서와 액추에이터가 필요한가요?
  - 주요 모니터링 대상은 무엇인가요? (온도, 습도, 토양 수분 등)
  - 사용자에게 어떻게 정보를 표시할 계획인가요?

## 2. 하드웨어 컴포넌트 선택
- **센서 구성**: 다음 중 어떤 센서를 사용할 계획인지 선택해주세요
  - DHT11 온습도 센서 (온도/습도 측정)
  - 초음파 센서 HC-SR04 (물 수위 측정)
  - XADC를 활용한 토양 수분 측정
- **출력 장치**: 다음 중 필요한 출력 장치를 선택해주세요
  - LCD 디스플레이 (HD44780/LCD1602)
  - LED 상태 표시기
  - 모터/펌프 제어 (급수 시스템)

## 3. 시스템 아키텍처 설계
- **모듈 구성**: 시스템을 어떻게 모듈화할 계획인가요?
  - 센서 인터페이스 모듈
  - 메인 컨트롤러
  - 사용자 인터페이스 모듈
  - 액추에이터 제어 모듈
- **통신 프로토콜**: 모듈 간 통신은 어떤 방식으로 구현할 계획인가요?

## 4. 기능 구현 계획
- **기본 기능**: 다음 중 우선적으로 구현할 기능을 선택해주세요
  - 토양 수분 측정 및 자동 급수
  - 온습도 모니터링 및 경고 시스템
  - LCD를 통한 상태 표시
  - 키패드를 통한 설정 변경
- **추가 기능**: 추후 확장 가능한 기능이 있다면 무엇인가요?

## 5. 개발 단계 설정
- **1단계**: 개별 모듈 개발 및 테스트
  - 센서 인터페이스 (DHT11, 토양 수분, 초음파 센서)
  - 출력 장치 제어 (LCD, LED, 모터)
- **2단계**: 모듈 통합 및 컨트롤러 개발
  - 중앙 제어 로직 구현
  - 모듈 간 인터페이스 구현
- **3단계**: 시스템 최적화 및 테스트
  - 동작 검증
  - 에너지 효율 및 반응성 개선

## 6. 테스트 계획
- **모듈 테스트**: 각 센서 및 출력 모듈을 어떻게 검증할 계획인가요?
- **통합 테스트**: 전체 시스템의 기능을 어떻게 검증할 계획인가요?
- **필드 테스트**: 실제 환경에서 얼마나 오래 테스트할 계획인가요?

## 7. 문서화 계획
- **코드 문서화**: 모듈 및 함수 설명, 인터페이스 정의
- **사용자 매뉴얼**: 사용 방법 및 문제 해결 가이드
- **시스템 다이어그램**: 하드웨어 연결 및 소프트웨어 구조 다이어그램
